Schedules

Schedules start a timer for you at a set time. They use this device’s local time zone . They only run while this LUNA page is open and the device is awake — nothing runs if the browser is closed or the device is off or asleep. A scheduled start never interrupts a timer that is running or paused: it is skipped and noted in Recent activity. A timer that has already finished is replaced.
